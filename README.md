구글 테스트인 gMock의 예시들을 c++을 사용해 실제로 어떻게 작동하는지 테스트 한 코드.
gmock 안에는 일반 테스트와 mock 테스트 둘다 들어가 있다.
일반적으로 tdd 라고 하면 일반 테스트를 의미하며, 서버같이 다른 라이브러리나 코드에 의존적일때(ex. db) 그 것 자체를 돌릴 수 없기 때문에 mock으로 가짜 객체를 만들어서 테스트
할 수 있게끔 한다.

일반 단위 테스트는 함수의 출력값이나 내부 상태 변화를 검증하는 데 초점을 둡니다. 입력에 대해 기대한 결과가 나오는지를 확인하며, 순수 함수나 내부 로직 중심 코드에 적합합니다.

반면 GMock 테스트는 외부 객체와의 상호작용을 검증합니다. 어떤 메서드가 호출되었는지, 몇 번 호출되었는지, 어떤 인자였는지를 판단하는 행동 기반 테스트입니다. 로깅, 네트워크 요청,
DB 저장 같은 작업이 실제로 실행되었는지를 확인할 수 있습니다.

일반 테스트는 결과가 틀리면 실패하고, GMock은 행동이 틀리면 실패합니다.
또한, GMock은 인터페이스 기반 설계와 의존성 분리를 필요로 하므로 테스트 가능한 구조를 강하게 요구합니다.

결과적으로, 일반 테스트는 "무엇을 리턴했는가?", GMock은 "무엇을 어떻게 호출했는가?"를 본다고 요약할 수 있으며, 이 둘은 병행 사용이 이상적입니다.
